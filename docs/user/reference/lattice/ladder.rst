Ladder Lattice
==============

One-dimensional two-leg (or multi-leg) ladder.

==============  ================================
Property        Value
==============  ================================
Canonical name  ``ladder``
Aliases         ``ladderlattice``
Dimensions      1D
Boost mode      Supported (see constraints below)
==============  ================================

Boost Mode Constraints
----------------------

- ``S2 = 1`` (S = 1/2 only)
- ``W = 2``
- ``L`` must be even and ≥ 4
