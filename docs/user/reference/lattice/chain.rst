Chain Lattice
=============

One-dimensional linear chain.

==============  ================================
Property        Value
==============  ================================
Canonical name  ``chain``
Aliases         ``chainlattice``
Dimensions      1D
Boost mode      Supported (see constraints below)
==============  ================================

Boost Mode Constraints
----------------------

- ``S2 = 1`` (S = 1/2 only)
- ``L`` must be a multiple of 8
