**Pain point**: `docs/index.rst` has title "StdFace Documentation" (21 chars) with underline of 20 `=` characters.

**Affected files**: `docs/index.rst`

## Issue 2: macOS resource fork files in repository

**Pain point**: Numerous `._*` binary files (macOS resource forks) are showing as untracked in git.

**Root cause**: Files created on macOS without proper `.gitignore` exclusion.

**Fix**: Add `._*` pattern to `.gitignore` (or global gitignore).

**Prevention rule**: Ensure `.gitignore` includes common OS-specific patterns (`._*`, `.DS_Store`, `Thumbs.db`).

**Affected files**: All `._*` files throughout docs/ and root directory.

# Phase 1 (Repo Cartography)

## Issue 3: No include/ directory - headers in src/

**Pain point**: claude.md Section 1 states "Public API is defined by public headers in `include/`" but this project has no `include/` directory. All headers are in `src/`.

**Root cause**: Project structure differs from typical C project layout. This is a design choice, not an error.

**Fix**: Document the actual location (`src/`) in header_map.yaml. Add explicit note that headers are in `src/`, not `include/`.

**Prevention rule**: Always verify assumed directory structures before documenting. Use Serena `find_file` to locate headers.

**Affected files**: `docs/_meta/header_map.yaml` (documented), claude.md (assumption noted)

---

## Issue 4: Conditional compilation affects API visibility

**Pain point**: `export_wannier90.h` functions (`ExportGeometry`, `ExportInteraction`) are only available when `_HWAVE` is defined. This conditional API is not immediately obvious.

**Root cause**: Functions are wrapped in `#if defined(_HWAVE)` preprocessor block.

**Fix**: Document the conditional in header_map.yaml with `conditional: "_HWAVE"` field.

**Prevention rule**: Always check for preprocessor conditionals when extracting API. Use Serena's symbol tools which may miss conditionally-compiled code.

**Affected files**: `src/export_wannier90.h`, `docs/_meta/header_map.yaml`
